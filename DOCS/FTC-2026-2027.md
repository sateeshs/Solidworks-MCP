## goBILDA StarterBot CAD vs. Pollen/Nectar

Currently open in SolidWorks: `3200-2627-0003.SLDASM` (`D:\__MyworkArea\Downloads\FTC\3200-2627-0003.SLDASM`) — the goBILDA BIOBUZZ StarterBot. Measured live via `execute_python` (`IComponent2::GetBox`): overall chassis envelope is **426 × 454 × 329 mm** (W×D×H), consistent with the 18″×18″×18″ FTC sizing rule.

**Can it intake Nectar? No** — confirmed from the CAD itself, not just marketing copy. Going one level deeper (`part_doc.FirstFeature`/`GetNextFeature` on the STEP-imported sub-part) revealed it isn't a dumb fused blob — it contains 170+ individually-named `Reference` features, real goBILDA SKUs (e.g. `5203-2402-0019.step` = Yellow Jacket motor, `1611-0514-4008.step` = flanged bearing). Sixteen of them are `3618-4008-0016 (Stretched over 8 REX)` — goBILDA's Intake Roller Wheel (8mm REX bore, **16mm diameter**, 30A durometer rubber).

**Confirmed from the actual assembly-instructions PDF** (goBILDA, 37 pages, read locally from `C:\Users\swath\Downloads\3200-2627-0003_assembly-instructions.min.pdf`): all 16 rollers mount on a **single 264mm-long, 8mm REX shaft** (Step 16, page 14) — one spinning roller drum spanning most of the chassis width, chain-driven off one 50.9:1 Yellow Jacket motor (Steps 15–17). Not a two-roller pinch pair — there is exactly one such shaft in the whole 37-page build (verified via full-text search for "264mm").

Since it's a single roller, there's no roller-to-roller gap to measure — the actual constraint is how the roller scoops the ball against the ground or a fixed frame member as the robot drives up to it, which the assembly manual doesn't dimension (it's a build guide, not an engineering drawing). Combined with every official goBILDA description of this StarterBot (base 6WD and Mecanum variants) explicitly claiming Pollen handling and never mentioning Nectar, the evidence converges: **the stock intake is built for the 2.8″ Pollen sphere, not the 3.6″/41g Nectar.** Nectar scoring would need a separate mechanism.

**Still open:** the exact roller-to-ground/frame clearance in mm — not dimensioned in the build manual; would need direct physical measurement of a built robot, or the SolidWorks COM geometry queries this project's automation layer can't currently resolve (`GetBodyBox`/`GetMassProperties`/`GetTypeName2` all fail on Feature/Body-typed objects here — a reproducible binding limitation).

Full StarterBot CAD-structure writeup: see the "BIOBuzz StarterBot" tab in the [Catapult Assembly - Functionality and Parts List](https://claude.ai/artifact/5Z66fdeN9LCpLzPtNryCm7) Claude Doc.

## Intake redesign: handling both Pollen and Nectar

A single fixed roller can't grip both sizes as-is: Nectar is 20mm bigger than Pollen, and the stock `3618-4008-0016` rollers (16mm OD, 30A rubber) only compress ~2-3mm — nowhere near enough to bridge that gap. Two approaches were evaluated; **A1 was chosen**:

| Approach | How | Trade-off |
| --- | --- | --- |
| **A1 (chosen): Nip-for-Pollen + scoop-for-Nectar** | Set roller-to-ground clearance close to Pollen's 71mm for true rolling engagement. Add a wide, low, sloped scoop lip beside/ahead of the roller that shovels the bigger Nectar in via the robot's forward driving momentum, not roller contact | Reuses the stock roller/drivetrain unmodified, only adds a static ramp/lip. Nectar handling is "push it in" rather than precise roller feed — simple and testable |
| A2 (not chosen, revisit if A1 underperforms) | Replace stock rollers with one larger-diameter (~40-60mm) soft foam roller with enough compression travel to grip both sizes by true contact | More correct long-term, but needs a custom/non-stock roller — bigger design/fab lift |

Build status: starting SolidWorks modeling of the A1 scoop/ramp addition.
